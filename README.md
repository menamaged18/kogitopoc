# Kogito + Spring Boot Integration & Workflow Guide

A cheat sheet and reference guide for configuring **jBPM / Kogito (1.44.x)** processes inside a **Spring Boot 3 (Java 17/21)** application.

---

## 1. Core BPMN Diagram Rules

Kogito strictly enforces BPMN 2.0 validation during the code-generation phase (`mvn compile`). Keep these constraints in mind when designing diagrams in VS Code or Business Central:

* **Single Incoming Connection Constraint:** 
  * Tasks (Script, User, Service) and End Events **cannot** act as merge points. 
  * Every Task and End Event must have **exactly 1 incoming sequence flow (arrow)**.
* **Merging Converging Paths:**
  * If multiple paths lead into the same task or end flow, merge them using an **Exclusive Gateway (XOR Join)** or **Parallel Gateway** *before* entering the target node.
  * Alternatively, split the flow into distinct **End Events** for each path.
* **File Location & Duplicates:**
  * Place `.bpmn` or `.bpmn2` process files under `src/main/resources/processes/`.
  * **Do not** keep duplicate diagram files in parent folders or subdirectories, as Kogito will throw duplicate Process ID execution errors.

---

## 2. Spring Boot Package Scanning Setup

During compilation, the `kogito-maven-plugin` generates application context beans under the `org.kie.kogito` package. Because Spring Boot only scans your base package by default, you must explicitly enable component scanning for Kogito.

### `Application.java` Configuration

```java
package com.example.project;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.annotation.ComponentScan;

@SpringBootApplication
@ComponentScan(basePackages = {"com.example.project", "org.kie.kogito"})
public class Application {

    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```
3. Maven Configuration (pom.xml)
When building with Spring Boot 3 / Java 17+, you need to handle legacy javax.annotation references generated by Kogito, as well as strict maven-compiler-plugin annotation processor requirements.

```XML
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="[http://maven.apache.org/POM/4.0.0](http://maven.apache.org/POM/4.0.0)" 
         xmlns:xsi="[http://www.w3.org/2001/XMLSchema-instance](http://www.w3.org/2001/XMLSchema-instance)"
         xsi:schemaLocation="[http://maven.apache.org/POM/4.0.0](http://maven.apache.org/POM/4.0.0) [https://maven.apache.org/xsd/maven-4.0.0.xsd](https://maven.apache.org/xsd/maven-4.0.0.xsd)">
    <modelVersion>4.0.0</modelVersion>
    
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.2.5</version>
        <relativePath/>
    </parent>
    
    <groupId>com.example</groupId>
    <artifactId>kogito-demo</artifactId>
    <version>0.0.1-SNAPSHOT</version>

    <properties>
        <java.version>21</java.version>
        <kogito.version>1.44.1.Final</kogito.version>
    </properties>

    <dependencies>
        <!-- Spring Boot Web Starter -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- Kogito Spring Boot Starter -->
        <dependency>
            <groupId>org.kie.kogito</groupId>
            <artifactId>kogito-processes-spring-boot-starter</artifactId>
            <version>${kogito.version}</version>
        </dependency>

        <!-- Legacy javax.annotation support for generated Kogito code in Java 11+ -->
        <dependency>
            <groupId>javax.annotation</groupId>
            <artifactId>javax.annotation-api</artifactId>
            <version>1.3.2</version>
        </dependency>

        <!-- Lombok -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <version>1.18.30</version>
            <optional>true</optional>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>

            <!-- Kogito Code Generation Plugin -->
            <plugin>
                <groupId>org.kie.kogito</groupId>
                <artifactId>kogito-maven-plugin</artifactId>
                <version>${kogito.version}</version>
                <extensions>true</extensions>
            </plugin>

            <!-- Maven Compiler Plugin with explicit Annotation Processor Versions -->
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <configuration>
                    <annotationProcessorPaths>
                        <path>
                            <groupId>org.projectlombok</groupId>
                            <artifactId>lombok</artifactId>
                            <version>1.18.30</version>
                        </path>
                    </annotationProcessorPaths>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>
```

4. Quick Execution & Build Commands
Compile process models & generate code:

```Bash
mvn clean compile
Run the application locally:
```

```Bash
mvn spring-boot:run
```

REST API Endpoint Convention:
Kogito auto-generates REST endpoints based on your process ID.

Process ID: my_process

Endpoint: POST http://localhost:8080/my_process
